  Interprétation [AHK18] :
  • C_L = nombre de niveaux Lefschetz distincts (vs C niveaux de poids)
  • W*_L ≤ W* : le sort Lefschetz concentre les arêtes MST en moins de niveaux
  • MST@10% : fraction d'arêtes MST dans les 10% premiers niveaux Lefschetz
    → valeur élevée = le score s_L = w(e)/sqrt(d_u·d_v) prédit le MST
  • Fondement : s_L ∝ sqrt[Q_β]_{e,e} diagonal de la forme Hodge-Riemann [AHK18]
    L'unique valeur propre positive de Q_β correspond à la direction MST.

  CHAÎNE DE CONTRIBUTIONS LGS :
  LGS          : early stop à W* via gradient Lorentzien g_i=|C_i|/|C_{i-1}|
                 Complexité O(m+C+E_{≤W*}·α(n)) — sublinéaire si W*<<C
  LGS-Bidir.   : W*_upper certifié O(C) par accumulation descendante
                 min(W*_pred, W*_upper) → borne plus serrée sans surcoût
  LGS-Skip     : déduplication des arêtes redondantes par paires de composantes
                 G_w = graphe de composantes au niveau w; rank(G_w) ≤ n_comp-1
                 [BH20 Cor 2.4] → |paires utiles| ≤ n_comp → skip des doublons
                 Gain maximal sur graphes à poids uniformes (AS-CAIDA, rgg):
                   s_i arêtes brutes → k_i ≤ n_comp paires → facteur s_i/k_i
  LGS-Lefschetz: sort bi-clé (w, s_L↓) avec s_L(e)=w(e)/sqrt(d_u·d_v)
                 s_L ∝ sqrt([Q_β]_{e,e}) — diagonale de la forme Q_β [AHK18 §6]
                 Résout les égalités de poids selon la structure Hodge-Riemann
                 Gain sur graphes avec poids peu discriminants (Bitcoin, AS-CAIDA)

  THÉORÈMES [AHK18] + [BH20] exploités :
  [AHK18 §6] Hard Lefschetz : Q_β sur A^1(M(G)) a signature (1,|E|-1)
              → [v*]_e ∝ s_L(e) = w(e)/sqrt(d_u·d_v) = direction MST
  [BH20 Cor 2.4] Log-concavité : rank(G_w) ≤ n_comp-1 ≤ n-1
              → |paires utiles par niveau| ≤ n-1 → borne sur le skip
  [BH20 Thm 1.1] Z_M Lorentzien : gradient g_i décroissant
              → W* = O(log n) en espérance → E_{≤W*} = O(m log n / C)

  PROBLÈMES OUVERTS JACM :
  1. Prouver k_i = O(sqrt(s_i)) en espérance sur G(n,p) — meilleure
     borne pour LGS-Skip via les graphes aléatoires de composantes.
  2. Prouver W*_L = O(W*/log n) sur power-law → LGS-Lefschetz optimal.
  3. Combiner LGS-Skip + LGS-Bidir : W* certifié + déduplication
     → O(m + C + Σ_{i≤W*_upper} k_i · α(n)) déterministe.
  4. T*(m,n) = Theta(m·alpha(m,n)) dans le modèle de comparaison ?

  Questions ouvertes (2026):
    * k_i = O(sqrt(s_i)) en espérance sur G(n,p) ?
    * Borne tight W*_L vs W* via la théorie de Lefschetz [AHK18] ?
    * LGS-Skip + LGS-Lefschetz combinés : gain multiplicatif ?
    * Extension aux matroides non-graphiques (représentables sur F_q) ?
    * MST dynamique LGS : maintenir W*, s_L, rank(G_w) sous mises à jour ?
